# 지역 의료이용 지도

공공 의료 통계로 시군구별 진료 현황을 전국 평균과 비교해 보는 정적 웹 지도입니다.

보여주는 값은 한 해 동안 진료받은 사람 수입니다. 새로 병에 걸린 사람 수(발생률)가 아닙니다. 개인의 질병 위험 예측이나 보험 상품 추천이 아니며, 병원 접근성이나 검진 참여 같은 의료 이용 여건도 값에 영향을 줍니다.

## 볼 수 있는 내용

- 229개 시군구의 2021~2025년 진료 통계
- 지표 12종과 전체 진료
- 전국 평균을 100으로 본 지수, 나이 구조 보정 여부 선택
- 지역별 95% 구간, 신뢰도, 연도별 변화
- 지도와 같은 내용의 표 보기

연령대 선택은 전체 진료에서만 됩니다. 질병별 시군구 자료에는 연령 구분이 없습니다.

## 실행

서버 코드 없이 정적 파일로 동작합니다. 브라우저 보안 때문에 `index.html`을 파일로 직접 열면 데이터를 읽지 못하므로, 정적 파일 서버로 여세요.

```bash
npx http-server . -p 8941
```

## 파일

| 경로 | 내용 |
|---|---|
| `index.html`, `css/`, `js/` | 지도 화면 |
| `about.html` | 출처, 계산식, 한계 |
| `data/metrics.json` | 시군구 단위 집계 지표 |
| `data/boundaries.json`, `data/sido.json` | 지도 경계 |
| `vendor/` | Leaflet 1.9.4 (BSD 2-Clause) |

원본 자료와 전처리 코드는 이 저장소에 없습니다.

## 출처와 이용 조건

- 국민건강보험공단, 「2021~2025 지역별 의료이용 통계연보」, 2022~2026, www.nhis.or.kr
- 국민건강보험공단, 「2021~2024 건강보험통계연보」, 2022~2025, www.nhis.or.kr
- 국가데이터처, 「SGIS 행정구역 통계 및 경계」, 2025년 2분기 기준, www.data.go.kr

공단 연보의 이용 조건은 공단에 문의해 확인하지 않았습니다. 공공데이터포털에서 공단이 같은 연보를 자유이용(제0유형, 일부 묶음 항목은 제1유형)으로 등록한 점을 근거로 이용했고, 공단 홈페이지의 연도별 게시물에는 공공누리 표시가 없습니다. 근거와 한계는 `about.html`을 보세요. 이 저장소의 값은 원자료를 합산하고 지수를 계산해 가공한 결과이며, 공단이나 국가데이터처가 작성하거나 검증한 값이 아닙니다.
